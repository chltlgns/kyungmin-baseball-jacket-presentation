# 경민대학교 야구점퍼 제안 발표자료

캠퍼스룩의 경민대학교 야구점퍼 제안용 웹 프레젠테이션입니다.

## 발표 조작

- 이전/다음 슬라이드: 방향키
- 전체화면: 브라우저 전체화면 기능(`F11`)
- 화면 채우기/전체 슬라이드 보기 전환: `F`

기본 화면은 브라우저 비율과 관계없이 검은 여백이 생기지 않는 `cover` 모드입니다. 이 모드는 화면 비율이 16:9와 다르면 슬라이드 가장자리를 일부 자를 수 있습니다. 전체 내용을 잘림 없이 보려면 `F`를 누르거나 URL 끝에 `?fit=contain`을 추가하세요.

## 다시 생성하기

```bash
node scripts/prepare-deck.mjs "원본.html" index.html
```
